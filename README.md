# Machinery Manufacturer Storefront & Tracker

🔗 **Live Demo:** [https://leadspree-dev-official.github.io/machinery-manufacturer-storefront/](https://leadspree-dev-official.github.io/machinery-manufacturer-storefront/)

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- TypeScript
