- **Build:** Vite + React 19 + Tailwind CSS v4 + TypeScript
- **Developer:** Aniruddha Das | [LeadSpree Business Solutions](https://leadspree.in)

## Brand Demo Onboarding

Every app includes:
- Glassmorphism-free dark onboarding modal (brand name, contact, phone, address, color picker)
- 3-hour auto-reset session policy with live countdown
- Floating brand reset button (bottom-right)
- Admin console at `/admin` (PIN: 1234)
- `data-brand-text` attributes on header/footer for dynamic brand text

## Notes

- AI features (Gemini API) require a `GEMINI_API_KEY` environment variable
- Express backend features (server.ts) are not available on GitHub Pages (static hosting only)
- Push to `main` to trigger automatic redeployment
